# Ecos de Quisqueya

Plataforma en pixel art para conversar con recreaciones, hechas con IA, de tres figuras de la historia dominicana:

- **Salomé Ureña**: poeta y educadora.
- **Juan Pablo Duarte**: padre fundador de la República.
- **Juan Bosch**: escritor y político.

## Cómo abrirlo

Abre `index.html` en el navegador. Es un solo archivo, sin instalación.

## Qué funciona dónde

- **Dentro de Claude** (como artefacto de claude.ai): conversación libre con IA, voz y dictado.
- **Fuera de Claude** (por ejemplo, en GitHub Pages o abriendo el archivo): esas tres funciones no están disponibles, y los personajes responden las preguntas sugeridas.

Las respuestas son recreaciones generadas para aprender: no son citas textuales de los personajes.
